# 媒体文件同步删除（V3）

插件响应媒体服务器删除事件，清理对应的整理历史；开启“删除源文件”后，同步删除对应源文件并处理下载任务。

## 删除范围

- 只处理整理成功、源和目标存储均为 `local` 的完整历史。
- 源文件必须位于 MoviePilot“目录”配置的本地下载目录下，目标必须位于本地媒体库目录下。未配置、配置读取失败、非本地存储或路径不匹配时保留历史。
- 媒体服务器与 MoviePilot 路径不同时，需要配置目录前缀映射；映射后的电影/单集路径必须与历史目标完全一致，整剧/整季事件只处理事件目录下的历史。
- 目标文件仍存在、已重新生成、路径含符号链接或源仍被其他现存库文件引用时，跳过同步删除。
- 不删除下载根或媒体库根，不递归删除目录；最多向上清理三级空目录，同目录的字幕、图片和其他文件会保留。

## 下载任务与失败重试

部分文件尚未删除时暂停下载任务；全部文件已删除时移除下载任务。下载器不会额外删除数据文件，文件清理由插件在上述范围内逐文件执行，避免共享种子或合集连带删除其他文件。

源文件或下载器清理失败时保留整理历史，继续处理其他记录，不写入该条的成功结果。排除故障后可以重新发送同一删除事件；源文件已经删除时仍能重试下载器清理。通知中的删除记录数只包含完成清理的记录，种子数按已确认处理成功的哈希去重统计（同哈希在不同下载器上合并计数）。
